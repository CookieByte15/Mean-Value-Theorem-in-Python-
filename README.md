# Mean Value Theorem

A simple Python program that demonstrates the **Mean Value Theorem** using numerical computation.

## Formula

For a function continuous on `[a,b]` and differentiable on `(a,b)`:

```text
f'(c) = (f(b) - f(a)) / (b - a)
```

## Features

* Takes a mathematical equation as input
* Accepts an interval `[a,b]`
* Uses numerical approximation
* Returns the approximate result

## Run

```bash
python mean_value_theorem.py
```

### Example

```text
Equation: x**2 - 4
a: 0
b: 5

Root found at approximately x = 1.9999980926513672
```
